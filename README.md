# Squadala! for macOS

An Apple Silicon port of [Squadala!](https://github.com/daurosk/oot-remake-multiplayer), the Ocarina of Time remake co-op project. This port runs on nxnative and uses the shared Squadala co-op code.

The active branch is `macos-squadala-v0118`. It is based on Squadala v0.11.8 (protocol 15). The Mac build is experimental, and Windows cross-play is still being tested.

- [Build, install, or update on Apple Silicon](https://github.com/carlosxfi/oot-remake-multiplayer-macos/tree/macos-squadala-v0118#build-and-play-on-a-mac)
- [Report a Mac bug](https://github.com/carlosxfi/oot-remake-multiplayer-macos/issues)
- [Contribute to the Mac port](https://github.com/carlosxfi/oot-remake-multiplayer-macos/tree/macos-squadala-v0118#help-with-testing-and-development)

The repository provides the co-op source under [GPL-3.0](LICENSE). Use your own local game data to build the asset pack.
